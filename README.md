# 함끼 (Hamkki)

> **AI가 고르고, 함께 정하는 한 끼** · Pick together, eat together.

상황과 조건을 입력하면 AI가 근처 식당 3곳을 이유와 함께 추천하고, 같이 갈 사람들과 링크 하나로 투표해서 정하는 모바일 웹서비스입니다.

- 배포 주소: https://hamkki.onrender.com
- 소프트웨어학과 2221042 이유빈 · 3회차 프로젝트

## 주요 기능

| 기능 | 설명 |
|---|---|
| 장소 검색 | 역·동네·건물 이름 자동완성 (카카오 로컬 API). 처음 검색한 지역은 그 자리에서 식당을 수집 |
| 현재 위치로 찾기 | 휴대폰 위치로 바로 검색 (동네 이름만 표시, 위치는 약 100m 단위로 흐리고 저장하지 않음) |
| 조건 입력 | 상황(데이트·가족·친구·회식·혼밥), 인원, 시간대, 예산, 음식 종류, 원하는 분위기(자유 문장) |
| **AI 추천** | Gemini가 후보 20곳 중 상황과 분위기 문장에 맞는 3곳을 고르고 추천 이유를 작성 |
| 지도 | 추천 식당을 번호 핀으로 표시, 카카오맵 상세 정보·길찾기 링크 |
| **조건 덧붙여 재추천** | "더 저렴한 곳으로", "다른 종류로"처럼 문장을 덧붙이면 이전 추천을 피해 다시 추천 (최대 3번) |
| **동행자 투표** | 추천 결과로 투표 링크 생성 → 로그인 없이 이름만 적고 투표, 득표 현황 실시간 집계 |
| 최종 결정 | 투표를 만든 사람이 '여기로 결정' → 투표 마감, 모두에게 결정 식당과 길찾기 표시 |
| 공유 미리보기 | 카톡으로 링크를 보내면 지역·후보 이름이 담긴 미리보기 카드 |
| 추천 만족도 | 결과마다 👍👎(아쉬운 이유 선택) → 관리용 통계 페이지에서 만족도·재추천 효과·투표 전환율 확인 |

## AI가 하는 일 (왜 if문으로는 안 되는가)

"부모님 모시고 조용히", "오랜만에 만나서 얘기 많이 할 곳" 같은 문장은 정해진 규칙으로 처리할 수 없습니다.
서버가 거리·음식 종류·상황 규칙으로 후보 20곳을 추리면, Gemini가 문장의 의도를 해석해 3곳을 고르고 이유를 설명합니다.

AI가 없는 식당을 지어내지 않도록 다음 안전장치를 두었습니다.

- AI에게는 서버가 고른 후보 목록만 주고, 돌아온 ID가 실제 후보인지 서버가 다시 검사
- 가격·분위기·영업시간 정보가 없다는 것을 알려 주고 단정하지 않도록 지시
- AI가 실패하면(쿼터 초과, 네트워크 오류 등) 화면이 깨지지 않고 후보 목록을 대신 보여줌
- 무료 쿼터 보호: 한 사람당 10분 6회, 하루 전체 300회까지만 AI 추천

## 기술 스택

- **백엔드**: Python, Flask, gunicorn
- **AI**: Google Gemini API (`google-genai`)
- **데이터**: 카카오 로컬 API (음식점 카테고리 검색, 키워드·주소 검색)
- **지도**: 카카오맵 JavaScript SDK
- **화면**: Jinja2 템플릿, Bootstrap 5, 모바일 기준(최대 폭 480px)
- **배포**: Render (+ Render Postgres: 투표·실행 중 수집한 칸 저장)

## 식당 데이터 수집 방식

지도를 약 1km × 1km 칸(타일)으로 나눠 칸 단위로 수집합니다.

- 칸 번호는 좌표로만 정해지므로 어떤 이름으로 검색해도 같은 칸을 재사용 → 중복 수집 없음
- 카카오 검색은 한 번에 최대 45곳 → 넘치면 칸을 4등분해 다시 수집
- 미리 모아 둔 지역(의정부시 전체 등) 밖은 사용자가 처음 검색할 때 자동 수집 (하루 한도 있음)
- 웹페이지 크롤링 없이 공식 API만 사용, 리뷰 원문은 저장하지 않음

## 로컬 실행

```
python -m venv venv
venv\Scripts\activate
python -m pip install -r hamkki_app/requirements.txt
```

`hamkki` 폴더에 `.env` 파일을 만들고 키를 넣습니다.

```
KAKAO_REST_KEY=...
KAKAO_JS_KEY=...
GEMINI_API_KEY=...
SECRET_KEY=...        # python -c "import secrets; print(secrets.token_hex(32))"
```

```
cd hamkki_app
python app.py         # http://localhost:5000
```

식당 미리 수집 (hamkki 폴더에서):

```
python collect_restaurants.py --area 의정부시
python collect_restaurants.py 홍대입구역 강남역 --radius 1500
```

```
├── render.yaml              Render 배포 설정
└── hamkki_app/

    ├── ai_recommend.py      Gemini 추천
    ├── vote_store.py        투표 저장

```
