## 1. AI 기능 (Gemini 추천)

| # | 문제 | AI 초안 | 수정 | 확인 방법 |
|---|---|---|---|---|
| 1 | AI가 없는 식당을 지어낼 수 있음 | 프롬프트로 "후보 안에서만 고르라"고만 지시 | 서버가 돌아온 ID를 실제 후보와 대조하고, 후보 밖이면 결과를 버림 | 후보 밖 ID가 섞인 응답에서 해당 식당 제외 확인 |
| 2 | 안내문의 `gemini-2.5-flash`를 신규 계정에서 쓸 수 없음 | 모델 하나만 고정 | 모델 목록을 순서대로 시도, `.env`의 `GEMINI_MODEL` 우선 | 실제 호출 성공 모델 로그 확인 |
| 3 | AI 응답이 늦으면 화면이 멈춤 | 타임아웃 없음 | 모델당 20초, 전체 40초 제한, 실패 시 후보 목록 표시 | 네트워크 차단 상태에서 화면 유지 확인 |
| 4 | 재추천 요약 문장이 프롬프트 예시와 똑같이 나옴 | 프롬프트에 예시 문장 포함 | 예시를 빼고 "요청에 맞게 구체적으로" 지시 | 요청마다 다른 요약 문장 확인 |
| 5 | 두 번째 재추천에서 처음 추천이 다시 나옴 | 직전 추천 3곳만 AI에게 전달 | 지금까지 보여준 식당 전부를 기억하고, 서버에서 AI 후보 목록에서 아예 제외 | 3회 연속 추천에서 겹치는 식당 0곳 |

## 2. 네트워크·환경

| # | 문제 | AI 초안 | 수정 | 확인 방법 |
|---|---|---|---|---|
| 6 | 학교 네트워크에서 `CERTIFICATE_VERIFY_FAILED` | (흔히 나오는 해결책) `verify=False`로 검사 끄기 ※당시 초안 확인 필요 | 검사를 끄지 않고 `truststore`로 운영체제 인증서 사용 | 학교 PC에서 Gemini·카카오 호출 성공 |
| 7 | venv가 아닌 파이썬으로 실행하면 같은 오류 재발 (`Basic Constraints not marked critical`) | truststore가 없으면 기본 설정 사용 | 원인: 파이썬 3.13부터 켜진 엄격 검사. 체인 검증은 유지하고 그 형식 검사 하나만 해제, 실행 중인 파이썬 경로 경고 | 두 파이썬 모두에서 연결 확인 |
| 8 | 의정부 전체 수집 중 연결이 끊겨 수집 전체 중단 (`SSLEOFError`) | 오류 시 그대로 종료 | 최대 3번 재시도, 그래도 실패한 칸만 건너뛰고 재실행 시 그 칸만 수집 | 재실행 후 114칸 오류 0개로 완료 |
| 9 | 배포 서버에서 공유 링크가 `http://`로 생성될 수 있음 | Flask 기본 설정 | Render 프록시 뒤에서 `ProxyFix` 적용 | 프록시 헤더를 흉내 낸 시험에서 `https://` 링크·Secure 쿠키 확인 |

## 3. 데이터 수집

| 13 | 시험 중 넣은 임시 좌표가 실제 장소 목록에 저장됨 | 시험을 실제 데이터 폴더에서 실행 | 잘못 저장된 항목 삭제 (교훈: 시험은 실제 데이터와 분리) | `places.json` 확인 |

## 4. 지도·투표

| # | 문제 | AI 초안 | 수정 | 확인 방법 |
|---|---|---|---|---|
| 14 | 카카오맵 링크가 `http://`이고 앱 미설치자를 고려 안 함 | 수집 데이터의 `place_url` 그대로 사용 | 식당 ID로 `https://` 웹 주소 생성, 길찾기도 웹 링크 | 링크 주소 확인 |
| 15 | 물방울 핀을 돌리면 번호도 같이 기울어짐 | 핀 전체 회전 | 번호만 반대로 회전 | 화면 확인 |
| 16 | 지도 키·도메인 문제 시 지도 칸이 빈 채로 멈춤 | 실패 처리 없음 | 10초 제한, 실패 시 지도만 숨기고 안내 | 도메인 미등록 상태에서 확인 (실제로 401 발생 → 콘솔 등록으로 해결) |

| 18 | 동시에 투표하면 한 사람 표가 사라질 수 있음 | 읽고-쓰기 그대로 | 저장 중 잠금, 파일 한 번에 바꿔치기 | 연속 투표 집계 확인 |
| 19 | 투표 주소에 `../`를 넣어 다른 파일을 읽을 위험 | ID를 그대로 파일 경로에 사용 | ID 모양 검사 | 이상한 주소 404 확인 |

## 남은 한계 (알고 있지만 의도적으로 둔 것)

- 로그인이 없어 다른 사람 이름을 적으면 그 사람 표를 바꿀 수 있음 (친구끼리 쓰는 용도라 허용)
- 카카오 데이터에 가격·분위기·영업시간이 없어 AI는 이름·종류·거리로만 추정
- 폐업 식당 미처리
- Postgres 이전 전까지 배포 서버의 투표·수집 데이터는 서버 재시작 시 사라짐
